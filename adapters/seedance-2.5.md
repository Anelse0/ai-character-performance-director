# Seedance 2.5 适配器

Seedance 2.5 与 2.0 的核心差异:2.5 是 **30 秒单次 one-take**(一次生成即一整场戏的 shot brief),官方称可**扩展两次**以延长;reference-to-video 能理解参考视频的意图、构图与镜头语言;单次最多 **30 图 + 10 视频 + 10 音频**参考;支持专业运镜、performance blocking 与**时间戳级编辑**——以上为官方确认项。原生分辨率、prompt 对**秒级 timestamp 的稳定响应**、以及"编号绑定素材"的具体写法来自第三方指南,官方页未确认,**以实测为准**。能力与边界见 `references/evidence-ledger.md` `[S25-CAP-01]`。

## 四段 prompt 结构(第三方归纳官方示例)

第三方指南归纳自官方发布示例的结构 `[S25-FORMULA-01]`(状态 `experimental`,非一手官方文档);正文按此顺序:

1. **素材引用**:给每个上传素材编号并绑定角色(如 `{{图1}}`=身份、`{{图2}}`=服装),不在图上打文字标签。
2. **一句话总纲**:主体 + 地点 + 事件 + 风格/类型 + 主运镜,合成一句。
3. **具体情节**:按 `timestamp` 或 `Shot N` 分段,逐段写画面、运镜、动作、对白、声音;尽量正向措辞。
4. **收尾约束**:角色一致性、光调、声音设计、贯穿全片的规则(如无字幕、无水印)。

叙事内容用 `Shot N`(保留节奏弹性);需要卡点/音画同步时用秒级 `timestamp`。

## 渲染要点

- **把情绪外化成身体细节**:用可见生理动作(颤抖的肩、攥紧的手、吸气—停住)代替"很悲伤/deeply emotional"。
- 偏好**缓慢、连续的小动作**;避免奔跑、跳跃、复杂手部等爆发式动作。
- 动作之间写**连接组织**,保持 30s 内连续,不在分段边界重起势。
- **单独一段写光**(方向+冷暖+对比);光对画质影响最大。
- 一镜只做**一个主运镜**;起幅、落幅可写,但不承诺精确相机轨迹。

## 长篇情绪表演(旗舰用法)

单主体持续情绪独白/告别按 `references/longform-performance-pattern.md` 的五层骨架渲染,映射到 2.5:

- L1 身份契约 → 四段结构第 1 部分(编号素材)+ 第 4 部分(一致性清单)。
- L2 场景总纲 → 第 2 部分一句话总纲 + 光照段。
- L3 单一情感事实 → 写在总纲之后,作为唯一主线,不拆成 beat。
- L4 递进镜头段落 → 第 3 部分,用 `镜头 01–N`;每镜=情绪推进 + 一个外显生理动作 + 可选一句对白 + 景别递进(中近→近→极近);越肩前景保留模糊肩部,焦点始终在主体脸上;结尾停在情绪悬而未决。
- L5 持续约束重述 → 第 4 部分收尾约束,把 L1/L2/L3 完整重述一遍。30s one-take 最依赖这一层对抗漂移。

## 不得宣称

- one-take 30s 等于对镜内每个微表情精确卡秒;
- R2V 参考一致性等于跨 30s 身份绝对不漂移;
- 负面提示词(除字幕/音频控制外)稳定服从;
- 秒级 timestamp 等于精确相机关键帧或口型完美同步;
- 把第三方来源的原生 4K/1080p 分辨率、prompt 秒级 timestamp 稳定响应当作官方保证;
- Seedance 2.5 必然优于其他模型或适合所有对白。
