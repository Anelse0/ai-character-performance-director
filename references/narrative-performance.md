# 剧情表演编排器

## 模式契约

剧情表演必须让人物行为产生可追踪后果。至少改变以下一项：

- 角色知道的信息；
- 人物间距离、信任或权力；
- 物件的持有、位置或意义；
- 谁获得话轮或行动权；
- 一个决定、承诺、拒绝或不可逆行动。

核心结构：

```text
event
→ reaction owner
→ action choice
→ other character response
→ narrative consequence
```

## Reaction Ownership

每个 beat 只指定一个主要 reaction owner。其他角色必须处于明确状态：继续说、等待、观察、保持任务、被打断或退出。

多人场景先列内部调度：

```yaml
beat_1:
  event:
  owner:
  other_characters_state:
  consequence:
```

不要把该结构原样塞进最终 Prompt；渲染为自然事件顺序或逐镜内容。

## 行动必须推动剧情

优先使用能改变场景关系的动作：

- 把证据放到两人之间；
- 收回准备交出的物件；
- 增加或缩短距离；
- 停止回答并提出一个精确问题；
- 选择不解释、转身、留下或离开；
- 中断对方的动作，而不是仅做更强表情。

手势、视线和呼吸应服务这些行动，不应成为独立装饰。

## 单镜与多镜决策

坚持单镜：

- 核心价值是看到一个反应从 onset 到 consequence 的连续性；
- 3–5 个主 beat 可以在 4–10 秒内完成；
- 说话者少、空间关系稳定、口型归属简单。

拆成多镜：

- 多个说话者、打断或不同 reaction owner；
- 超过 6–7 个主 beat；
- 需要证据物特写、正反打或位置变化；
- 一个镜头内无法同时清楚看到动作和听者反应。

每镜只承担一个戏剧任务：建立刺激、处理、说话、听者反应、行动后果或余波。不要把接收、崩溃和恢复塞进同一个两秒 reaction shot。

## 连续性账本

多镜头时记录并传递：

```yaml
knowledge:
distance_and_orientation:
held_objects:
gaze_target:
body_residue:
unfinished_action_or_line:
```

上一镜的 end state 是下一镜的 baseline。若上一镜下颌仍紧、手已离开钥匙或一句话未说完，下一镜不得无意重置。

## 道具与空间

只保留具有剧情功能的道具。每个道具动作写清：谁、对什么、方向、次数和后果。

距离变化使用有限尺度：靠近一步、退半步、身体朝出口转开。不要反复来回走动或同时交叉遮挡。

## 结束责任

明确最后一拍由谁持有，以及其他角色正在做什么或停止什么。剧情后果可以是：

- 一个问题无人回答；
- 物件留在两人之间；
- 某人面对出口，另一人留在原位；
- 一方停止争辩，话轮转移；
- 角色做出行动，但情绪尚未释放。

## 常见错误

- 所有人同时“情绪强烈”；
- 两个角色始终互盯、持续点头；
- 代词导致说话者与反应者漂移；
- 动作很多但没有任何剧情状态改变；
- 正反打之间身体、物件和情绪残留重置；
- 用更大表情代替质问、拒绝、退出或修复行动。
