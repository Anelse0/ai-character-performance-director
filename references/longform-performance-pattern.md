# 长篇情绪表演范式(单主体持续独白/告别/隐忍)

## 1. 职责与适用

本 Reference 提供一个**模型无关**的可复用骨架,用于 `actor_cut` 的长篇特例:单一主体、≥15 秒、以持续情绪弧为内容的表演(告别、隐忍重逢、强撑决心、压着愤怒的原谅、临别记住对方等)。它源自一条用户已验证的 Seedance 2.5 30 秒告别独白 `[USER-SD25-01]`。

适用信号:单主体对镜或越肩、少动作多微表演、有分段对白、情绪逐步升级但克制、结尾悬而未决。

不适用:多人动作剧情、强物理动作、需要可追踪剧情后果的 `narrative`、或短于约 6 秒的即时反应(用普通 `actor_cut` 分段框架即可)。

骨架本身跨模型通用;**变化的只有渲染层(时长预算、分段语法、身份绑定、镜头执行),不是骨架本身。** 分模型渲染见第 4 节与各适配器。

## 2. 五层骨架

顺序不可乱,每层一个独立职责:

```text
L1 身份契约        谁,全片必须不变(正向一致性清单,不用否定词堆一致性)
L2 场景总纲(一句话)  时长+情绪强度+时空+氛围+光方案+镜头关系+一个主运镜
L3 单一情感事实      一句"因果三段" + 情绪叠层(全片唯一主线)
L4 递进镜头段落      Shot 01–N;每镜=一次情绪推进+一个外显生理动作+可选一句对白+景别递进
L5 持续约束重述      把 L1/L2/L3 在结尾再声明一遍,作为贯穿全片的持续约束
```

**L5 就是用户原 prompt 里的「表演指导」块。** 它不是冗余复述,而是把"每一秒都成立的非时序约束"(身份、光、镜头关系、单一情感事实)与"时序性的分镜列表(L4)"分开声明。作用:

- 在长镜头(尤其 30s one-take)里,对抗身份漂移、景别漂移和情绪主线被单个 beat 劫持;把这些重新加权为"场景级持续约束",而不是模型会"走过"的开场条件。
- 它同时等价于业界四段式 prompt 公式的第 4 部分「closing constraints」(角色一致性、光调、贯穿规则)。
- 时长越长、one-take 越依赖它;短模型(如 Kling 8s)可精简重述,避免稀释(见第 4 节)。

## 3. 六个设计内核(可迁移,不是台词本身)

1. **单一情感事实是主轴**:一句因果三段(仍爱着 / 已决定离开 / 正逼自己说出口)锁死方向,再用情绪叠层提供质感。模型有唯一 throughline 才不飘。
2. **对白夹在两个生理动作之间**:台词前有准备动作(吸气/移开视线),台词后有反应(陷入沉默/表情动摇)。把不可控的"情绪"翻译成可拍的"动作"。
3. **景别递进 = 情绪递进**:中近景→近景→极近景,配一个**唯一主运镜**(如越肩缓慢前推)。镜头运动是情绪升级的结果,不是特效。
4. **决心是张力而非结局**:结尾停在悬而未决(在真正崩溃前结束),留残余,不重置到中性,也不给完整解决。
5. **否定式表演(减法)**:咽回去、停住、没擦眼泪、没转身、没离开——用"没有做什么"演克制,信息密度高。
6. **交互对象在场但被隐藏**:越肩前景保留模糊肩部,主体永远是她。对象存在并驱动情绪,却不占画面(对易增生外部实体的模型是关键风险点,见 Kling 渲染)。

## 4. 分模型渲染矩阵

骨架不变;每个模型只调整渲染层。详细规则见对应适配器。

| 维度 | Seedance 2.5 | Seedance 2.0 | Kling 3.0 |
|---|---|---|---|
| 时长 | 30s **one-take** 承载整条弧;更长按 extension 续写为 video2… | 约 15s/次;超出则**切成多条可运行 prompt(video1/video2…)**,不砍内容 | 单次 ≤15s;超出则**多条 prompt(video1/video2…)**;单次内用 Custom Multi-Shot(≤6 镜) |
| L4 分段语法 | Shot N(叙事优先);秒级 timestamp 响应为第三方所述,以实测为准 | **只用 Shot N**;秒级时间点不稳定,不写精确卡秒 | Actor Cut 情绪用**强制时间分段框架**`【0–t｜状态】`;多镜用逐镜时长 |
| L1 身份绑定 | R2V **编号素材**(`{{图1}}`=身份、`{{图2}}`=服装),≤50 参考 | 多模态参考素材绑定;正文正向声明一致性 | **Omni + element reference** 承担跨镜身份;character/voice binding |
| L2 主运镜 | 连续 prose 前推,起幅/落幅可写 | 连续因果 prose,复杂路径优先视频参考 | 一个主运镜;Prompt 或 UI Camera Movement 二选一,不承诺精确路径 |
| 视线对象隐藏(核心#6) | 越肩模糊肩部通常可直接渲染 | 同 2.5,但正文只保留获准主体 | **高风险**:越肩前景易增生第二张脸/多余的手;按 `references/interaction-performance.md` 做正向单主体契约与首帧门禁,必要时改**正面对镜**去掉越肩 |
| 情绪外化 / 慢速小动作 | 三模型通用强项,全部保留 | 同左 | 同左;避免爆发式大动作与复杂走位 |
| L5 重述强度 | 完整重述(30s 最需要) | 完整或适度重述 | **精简重述**(单镜短时长过度重述会稀释),多镜时把持续约束分摊进每镜 baseline |

### 4.1 内容超出单次生成上限:多片输出,不砍内容

当整条弧超出目标模型**单次生成的时长上限**时,默认**按内容的自然阶段切成多条独立可运行的 prompt**(`video1`、`video2`…),每条都在该模型单次上限内,合起来覆盖完整内容。**不以删减 beat 作为默认应对。**

先分清三个层级,不要混用:

- **镜头分段(Shot N / 分段框架)**:单次生成**内部**的 beat 顺序,始终使用。
- **多片输出(video1/video2…)**:内容超出单次上限时的**跨生成**切分,这是默认。
- **压镜(砍 beat、合并对白)**:**仅**当用户明确要"单条成片 / 不接受多段"时才用的降级。

多片输出的衔接三要素:

1. **身份**:每条 prompt 都完整重复 L1 身份契约(编号参考图 `{{图1}}`/`{{图2}}`)。
2. **接续**:`video_{n+1}` 从 `video_n` 的结束状态/末帧接续——Seedance 用 extension 续写,Kling 用末帧或 element reference;正文写"承接上一段的姿态/泪光/未说完的话",不重新起势。
3. **主线**:每条都重述 L3 单一情感事实,保证跨片主线不断。每条内部仍用 L4 承载该段的 beat 与对白。

切分点选在内容的**情绪阶段边界**(如 video1=辨认+说出口、video2=接近失控+告别),不在句子中间硬切。输出时逐条给出 `video1 / video2 …` 的可运行 prompt 与各自时长。

非模板性:骨架是脚手架,不是"情绪→动作"固定映射。同一情感事实在不同关系、景别、模型下必须重新选择外显动作;换模型/时长/镜头后仍需实拍验证,不把一次成功外推为通用保证。

## 6. 可填空模板

把骨架参数化,换任意情绪场景填空即用。这是内部脚手架,最终 Prompt 按目标适配器渲染,内部字段不逐字堆入:

```text
【L1 身份契约】
使用 {{角色参考图A}} 作为唯一{{角色}}身份参考,全片保持身份高度稳定一致:
脸部结构、五官、发型、肤色、视觉年龄、整体气质、辨识度。服装保持与 {{参考图B}} 一致。

【L2 场景总纲 — 一句话】
生成一段 {{时长}} 的 {{情绪强度}} 情绪表演。{{时间+地点}},氛围 {{氛围词}}。背景简单克制,不抢注意力。
{{光方案:方向+冷暖+对比}},在脸上形成 {{明暗层次}}。{{需清晰可见的生理信号:湿润/泛红/颤抖/呼吸}}。
镜头:{{视角与构图}},焦点始终锁定在 {{主体}} 脸上。{{一个主运镜}} —— 含义是 {{该运镜为何发生}}。

【L3 单一情感事实】
整段只围绕一个核心情感事实:{{她仍然 X}}。{{她已经决定 Y}}。{{她正在逼自己 Z}}。
此刻情绪同时包含:{{3–6 项情绪叠层,含一项“脆弱但强撑的决心”}}。

【L4 递进镜头段落】(每镜:情绪阶段 → 一个外显生理动作 → 可选一句对白 → 说完的反应;景别逐镜递进)
镜头 01 — {{酝酿}}:{{准备动作}} → {{迟疑/中止}} → {{强迫继续}} → 对白“{{台词}}” → {{反应}}。景别 {{中近景}}。
镜头 02 — {{推进}}:…… 景别推进一档。
镜头 03 — {{接近失控}}:…… 近景,一个不可逆小动作(如一滴泪落下但不擦)。
镜头 04 — {{极限未崩溃}}:…… 极近景;在 {{情绪悬而未决}} 处结束,不给解决。

【L5 持续约束重述】
重申 L1 身份/服装、L2 光与镜头、L3 单一情感事实,作为贯穿全片的持续约束。
```

复用策略:L1 / L3 / L5 是可复用模块(换角色、换情感事实即可);L4 每场重写。可自建"情感事实库"(一批因果三段:告别/隐忍重逢/强装镇定/压着愤怒的原谅……)与"外显动作库"(一批生理动作片段:吸气—停住/移开视线—强迫回看/手指蜷起/想笑没笑成……)作灵感来源——但按上文非模板纪律,库不是"情绪→动作"的固定映射,同一情感在不同关系/景别/模型下需重选动作。

超出单次生成上限时,按 §4.1 把模板产出为多条 `video1/video2…`,每条重复 L1、承接末帧、重述 L3。

## 7. 生产步骤(6 步)

固定按此顺序产出,质量靠流程而非灵感:

1. 先定唯一情感事实(一句因果三段),**绝不先写画面**;写不出这句,说明场景还没想清。
2. 写身份契约,用正向一致性清单(脸/五官/发型/肤色/年龄/气质/辨识度),不用否定词堆一致性。
3. 写一句话总纲(主体+时长+强度+时空+氛围+光+镜头关系+一个主运镜)。
4. 把情感事实拆成 3–5 个递进 beat;每 beat 只放一个外显生理动作 + 至多一句对白;景别随情绪递进,镜头只做一个主运动。
5. 逐条把抽象情绪词翻译成可见生理动作(externalize),删掉所有纯形容词(很悲伤/很深情/cinematic)。
6. 末尾重述持续约束 → 跑生成 → 定位最先失效的那**一个** beat 或 Camera Unit → 只改那一段,不整条重写;内容超单次上限则按 §4.1 多片输出。
