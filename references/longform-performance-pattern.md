# 角色情绪表演范式(单主体长篇为已验证原型,含多形态)

> 文件名沿用历史(`longform-performance-pattern`),范围已扩展到"长篇"以外的情绪表演形态。

## 1. 职责与适用

本 Reference 提供一个**模型无关**的可复用**结构骨架**,用于以情绪表演为内容的角色视频 Prompt。它源自一条用户已验证的 Seedance 2.5 30 秒告别独白 `[USER-SD25-01]`(**单一情绪递进**形态,逐字存档见 `tests/fixtures/seedance25-30s-farewell-monologue.verified.md`),并覆盖另外两种形态。

适用信号:以角色情绪弧为主、少动作多微表演、有分段对白、有明确情绪走向与收束。

不适用:非情绪的动作/喜剧节奏、强物理动作、纯剧情推进而无情绪表演、短于约 6 秒的即时反应(用普通 `actor_cut` 分段框架即可)。

骨架本身跨模型通用;**变化的只有渲染层(时长预算、分段语法、身份绑定、镜头执行),不是骨架本身。** 分模型渲染见第 4 节与各适配器。

### 1.1 形态选择器(先选形态,再套骨架)

五层骨架(第 2 节)中 **L1 身份契约、L2 一句话总纲、L5 持续约束三层任何形态都不变**;随形态变化的只有 **L3 主线**与 **L4 递进**。据此**委托**给已有引擎,不在本文件重写其规则:

| 形态 | L3 主线 | L4 递进 | reaction owner | 委托给(不复制) | 验证状态 |
|---|---|---|---|---|---|
| **单一情绪递进** | 单一情感事实(因果三段) | 单调升级,结尾悬而未决 | 单一 | `references/actor-cut.md` | `user_verified` `[USER-SD25-01]` |
| **受激分层递进**(振荡式下沉) | **恒定核心不变**(如"仍有感情,怒下始终可见痛")+ 表面主导层轮转 | 升级与回落交替振荡、净方向单向;**每次轮转必须有可定位触发**(外驱:回应/沉默/停顿/动作/物件/声音;内驱:发现行动无效/做出决定/自我提醒);最重一拍用最轻音量收尾 | 单一 | `references/actor-cut.md`(画外听戏)+ `references/climax-failures.md` | `user_verified` `[USER-SD25-02]`(Seedance 2.5/30s) |
| **双人情绪交流** | 双方各自 WANT + 关系变化 | 交替反应,残余逐镜传递 | **每 beat 指定** | `references/narrative-performance.md` + `references/dialogue-listening.md`(+ 交互对象见 `references/interaction-performance.md`) | `experimental`(设计级) |

三形态共用第 2 节骨架与第 3 节质量内核;已验证格式的权威样本是 `templates/` 母版。差别只在 L3/L4 的写法(见 §6.1 变体)。

**设计边界(短时长情绪反转仍然禁止)**:约 10–15s 内做情绪大起大落/反转不符合表演规律,AI 成片读作假(`[USER-SD20-01]`)。**受激分层递进不是反转的回归**,它成立的三个前提缺一不可:①总时长 ≥30s 且每个情绪阶段独立成镜;②恒定核心全程不变,变的只是表面主导层;③**每次层轮转有可定位触发**——变化是"用触发买"的,不是情绪自己翻转。触发可**外驱**(对方回应/沉默/停顿/动作、物件变化、声音,见 `[USER-SD25-02]`)也可**内驱**(发现行动无效、做出决定、自我提醒的一次可见动作,见 `[USER-SD25-01]` 的轻摇头),但必须落在画面或声音里可被观众定位。三条件不齐时回退单一情绪递进,不硬做层轮转。

**节奏底线(写实情绪表演)**:带对白的情绪 beat **每镜 ≥6s**(两条已验证 30s 样本分别为 4 镜/~7.5s 与 5 镜/~6s;10s 塞 3 镜的失败样本 ~3.3s/镜)。该底线只适用于写实情绪表演;官方案例显示剧情驱动/动画题材可用更快切分,不受此限。

## 2. 五层骨架

顺序不可乱,每层一个独立职责:

```text
L1 身份契约        谁,全片必须不变(正向一致性清单,不用否定词堆一致性)
L2 场景总纲(一句话)  时长+情绪强度+时空+氛围+光方案+镜头关系+一个主运镜
L3 单一情感事实      一句"因果三段" + 情绪叠层(全片唯一主线)
L4 递进镜头段落      Shot 01–N;每镜=一次情绪推进+一个外显生理动作+可选一句对白+景别递进
L5 持续约束重述      把 L1/L2/L3 在结尾再声明一遍,作为贯穿全片的持续约束
```

**L5 就是用户原 prompt 里的「表演指导」块。** 它不是冗余复述,而是把"每一秒都成立的非时序约束"(身份、光、镜头关系、单一情感事实)与"时序性的分镜列表(L4)"分开声明。作用:

- 在长镜头(尤其 30s one-take)里,对抗身份漂移、景别漂移和情绪主线被单个 beat 劫持;把这些重新加权为"场景级持续约束",而不是模型会"走过"的开场条件。
- 它对应 Seedance 官方结构的第 4 部分「结尾——补充贯穿始终的细节:机位/运镜、环境/场景、声音、氛围」(`[S25-FORMULA-01]`,一手 official)。
- 时长越长、one-take 越依赖它;短模型(如 Kling 8s)可精简重述,避免稀释(见第 4 节)。

**L5 有两种已验证变体**(各 n=1,无法判定孰优,按场景选择):

- **变体 A·逐字重述**(`[USER-SD25-01]`):把头部的身份/场景/镜头/情感事实原样重述一遍。简单直接,适合单一递进。
- **变体 B·四维契约**(`[USER-SD25-02]`):拆成四个独立小节——**Performance Requirements**(情绪递进链+动作幅度包络+关键细节清单+恒定核心)、**Camera Language**(逐阶段景别与运镜计划)、**Sound Design**(写实声音白名单+输出通道排除)、**Style Keywords**(风格标签,贡献未隔离验证,可选)。信息密度更高,适合分层递进/复杂场景。

### 2.1 声音层(Seedance 类有声模型必写)

官方每镜组织的第 ④ 部分就是音频信息(`[S20-FMT-01]`),声音不是可选装饰:

- **写实声音白名单**:只列本场真实存在的声音——呼吸(及其变化)、对白、画外短回应、衣料摩擦、脚步、房间底噪、**句间沉默**(沉默也是声音设计)。
- **对白语言绑定**:显式声明对白语言(如"中文对白"),尤其 prompt 语言与对白语言不一致时。
- **输出通道排除**(官方唯一许可的负向类,`[S25-FORMULA-01]`):无 bgm/不要字幕/无文字叠加/无旁白/无 UI;音频可分维度控制(音效/bgm/对白)。这类负向排除的是输出通道,不是表演动作,与"护栏优先正向"原则不冲突。

## 3. 六个设计内核(可迁移,不是台词本身)

以下 6 条是已验证单一情绪递进原型的设计内核。换形态时**保留这些质量取向**,只按形态选择器(§1.1)调整 L3 主线与 L4 递进——例如"双人情绪交流"里第 1 条的"唯一 throughline"变为双方各自的 WANT,第 4 条的收束可以是关系新状态。

1. **单一情感事实是主轴**:一句因果三段(仍爱着 / 已决定离开 / 正逼自己说出口)锁死方向,再用情绪叠层提供质感。模型有唯一 throughline 才不飘。
2. **对白夹在两个生理动作之间**:台词前有准备动作(吸气/移开视线),台词后有反应(陷入沉默/表情动摇)。把不可控的"情绪"翻译成可拍的"动作"。
3. **景别递进 = 情绪递进**:中近景→近景→极近景,配一个**唯一主运镜**(如越肩缓慢前推)。镜头运动是情绪升级的结果,不是特效。
4. **决心是张力而非结局**:结尾停在悬而未决(在真正崩溃前结束),留残余,不重置到中性,也不给完整解决。
5. **否定式表演(减法)**:咽回去、停住、没擦眼泪、没转身、没离开——用"没有做什么"演克制,信息密度高。
6. **交互对象在场但被隐藏**:越肩前景保留模糊肩部,主体永远是她。对象存在并驱动情绪,却不占画面(对易增生外部实体的模型是关键风险点,见 Kling 渲染)。

### 3.1 已验证技巧集(来自两条 30s 验证样本的交集与并集)

写 L4 时可选用;每条标注来源。它们是**手法**,不是必选项,更不是情绪查找表:

1. **每镜一个情绪任务(内部纪律)**:每镜只承担一个明确的情绪任务,并在该镜**正文首句**体现;**输出标题保持裸标题(`镜头 N`),不带说明后缀**(`[USER-FORMAT-01]`)。带功能标题(SD25-02)与裸标题(SD25-01)两式均验证过,用户规范定为裸标题。
2. **残余回指**(SD25-02):下一镜开头显式回指上一镜的可见状态("爆发之后,她突然停下""刚才的愤怒开始露出底下的悲伤")——注意这是**同一条 prompt 内部**的跨镜回指,与跨 prompt 的"独立自足"规则不冲突。
3. **响度交替 + 最轻收尾**(SD25-02):响→轻→响→轻的动态曲线,最重的一句话用最轻的音量在最安静的房间里说。强度 ≠ 音量。
4. **泪水计量**(两条样本共有):眼泪当进度条配给——微红→通红→蓄泪→逼回→一滴落下(不擦)→更多。从不写"她哭了",只写眼泪所处的阶段。
5. **沉默写成 beat**(两条共有):沉默有时长、有功能("先沉默几秒""长停顿""说完后几秒只有不均匀的呼吸"),并进入声音设计白名单。
6. **动作幅度包络**(SD25-02):幅度随情绪阶段变化的显式曲线——克制→前倾放大→递减→完全静止。
7. **句内 delivery 演化**(SD25-02):台词标注句中变化("后半句声音开始发抖""最后几个字说得非常轻"),不只标注整句语气。
8. **触发经济**(两条对照):情绪变化的两种合法来源——**内驱**(她逼自己,SD25-01)或**外驱**(画外回应触发,SD25-02);变化必须有来源,不允许无因翻转。画外回应可用**功能描述**("给了一个不能让她满意的回答")或**具体台词**("That's not what I meant"),两式均已验证。
9. **对白夹生理动作**(两条共有,原内核 #2):台词前有准备动作、后有反应。

### 4.1 内容超出单次生成上限:多片输出,不砍内容

当整条弧超出目标模型**单次生成的时长上限**时,默认**按内容的自然阶段切成多条独立可运行的 prompt**(`video1`、`video2`…),每条都在该模型单次上限内,合起来覆盖完整内容。**不以删减 beat 作为默认应对。**

先分清三个层级,不要混用:

- **镜头分段(Shot N / 分段框架)**:单次生成**内部**的 beat 顺序,始终使用。
- **多片输出(video1/video2…)**:内容超出单次上限时的**跨生成**切分,这是默认。
- **压镜(砍 beat、合并对白)**:**仅**当用户明确要"单条成片 / 不接受多段"时才用的降级。

多片输出的衔接三要素:

1. **身份**:每条 prompt 都完整重复 L1 身份契约(编号参考图 `{{图1}}`/`{{图2}}`)。
2. **接续**:`video_{n+1}` 从 `video_n` 的结束状态/末帧接续——Seedance 用 extension 续写,Kling 用末帧或 element reference。正文**直接写出该起始的可见状态**(姿态/泪光/未说完的话),**不出现"承接上一段/上一个视频"之类模型不可用的引用**;模型无记忆,连续性靠显式首帧状态与 extension/末帧,不靠文字叙述上文。
3. **主线**:每条都重述 L3 单一情感事实,保证跨片主线不断。每条内部仍用 L4 承载该段的 beat 与对白。

切分点选在内容的**情绪阶段边界**(如 video1=辨认+说出口、video2=接近失控+告别),不在句子中间硬切。输出时逐条给出 `video1 / video2 …` 的可运行 prompt 与各自时长。

**Seedance 官方口径**(`[S20-FMT-01]` 一手):单一场景的「文戏」(长对话、**情绪递进**、单一路径移动)优先用**视频延长**实现连贯一镜;剧情转折或快节奏「武戏」才用分段拼接;实际常两者结合(延长生成连贯对话+拼接空镜/转场)。因此本 skill 的多片输出在 Seedance 上默认**video2 以「延长 video1」的方式产出**,而不是独立生成再硬拼——情绪连续性由模型的延长机制承担,prompt 只写延长段的新内容与承接可见状态。

## 6. 已验证格式的权威样本 = `templates/` 母版

原「可填空模板」已被真实母版取代并删除(`[USER-TEMPLATE-01]`):精确命中走母版实例化,同域新场景走 `templates/anchoring.md` 锚定转写——两者的格式权威都是母版逐字文本,不再经过抽象填空层。

### 6.1 L3/L4 形态变体(其余层不变)

换形态时 L1/L2/L5 照抄,只改 L3/L4(短时长情绪反转不作为形态,见 §1.1 设计边界):

- **受激分层递进(振荡式下沉,已验证 `[USER-SD25-02]`)**
  - L3:写**恒定核心 + 层清单**——`{{她一直压着 X}}。{{她既愤怒又被深深伤到}}。{{她想要对方真正 Y}}` + 情绪层列表(其中恒定的一层全程可见,如"怒下始终有痛")。
  - L4:每个情绪阶段独立成镜(≥6s),情绪任务写进该镜正文首句(标题保持裸标题);**每次主导层轮转写明可定位触发**——外驱(画外回应,功能描述或具体台词皆可)或内驱(发现行动无效/决定/自我提醒的一次可见动作);响度交替,最重一句最轻收尾;动作幅度包络(克制→放大→递减→静止);结尾停在净方向的终点(如耗尽的失望),不回到开场层。
  - 三前提(§1.1)不齐时回退单一递进。
- **双人情绪交流**
  - L3:双方各自 WANT + 一次关系变化(信息/距离/话轮/决定归属),不是单人独白。

双人目前为设计级(`experimental`),无成片验证;产出成片后按证据门禁回填。

## 7. 生产步骤(6 步)

固定按此顺序产出,质量靠流程而非灵感:

1. 先定唯一情感事实(一句因果三段),**绝不先写画面**;写不出这句,说明场景还没想清。
2. 写身份契约,用正向一致性清单(脸/五官/发型/肤色/年龄/气质/辨识度),不用否定词堆一致性。
3. 写一句话总纲(主体+时长+强度+时空+氛围+光+镜头关系+一个主运镜)。
4. 把情感事实拆成 3–5 个递进 beat;每 beat 只放一个外显生理动作 + 至多一句对白;景别随情绪递进,镜头只做一个主运动。
5. 逐条把抽象情绪词翻译成可见生理动作(externalize),删掉所有纯形容词(很悲伤/很深情/cinematic)。
6. 末尾重述持续约束 → 跑生成 → 定位最先失效的那**一个** beat 或 Camera Unit → 只改那一段,不整条重写;内容超单次上限则按 §4.1 多片输出。

第 0 步(换形态时):先按 §1.1 形态选择器确定是单一递进还是双人交流,再决定 L3/L4 写法与委托的引擎文件。
