# 质量门

生成最终答案前逐项检查。失败项必须修正后再输出。

## A. 语义与非模板性

- [ ] 有明确 WANT；只有场景需要时才有 HIDE/CONFLICT。
- [ ] trigger 能在画面或声音中定位。
- [ ] 至少内部比较过两个 playable strategy，最终策略由关系与目标决定。
- [ ] 删除情绪词后，动作仍能解释本场处境。
- [ ] 没有把视线、眉、泪、吞咽或姿态写成情绪真相指纹。

## B. 因果与节拍

- [ ] 每个关键动作能回答：因为什么、服务什么目标、改变了什么。
- [ ] 即时反应或短处理符合场景，不机械添加延迟。
- [ ] 每个 beat 只有一个主要表演意图；机械联动属于同一 Motion Unit，独立表达任务已删减、串行或转交动作控制。
- [ ] 时长容得下主 beats 与台词。
- [ ] 有明确 end state，或明确说明在 threshold 处切断。

## C. 镜头与互动

- [ ] 指令使用的动作在当前景别可见。
- [ ] 每个 beat 只有一个 reaction owner。
- [ ] 多角色的其他人有明确听、说、等待、继续任务或退出状态。
- [ ] 多镜头把上一镜残留带入下一镜。
- [ ] 镜头、灯光、环境没有抢占表演预算。

## C2. 复杂动作

- [ ] 已判断动作是简单串行链、多个镜头任务，还是需要精确驱动。
- [ ] 跳跃、转身或复合手势包含可读的准备、主动作和收势/落地，而不只是动作名称。
- [ ] 方向、速度、幅度、支撑/接触和镜头关系只保留当前动作必要的信息。
- [ ] 中近景没有把不可见的脚步细节当作关键控制；需要地面接触时已调整景别。
- [ ] 没有用增加分段数量掩盖同一瞬间的动作并发。

## C3. 对镜眼神与情绪参考

- [ ] 对镜且伴随头部/身体运动时，使用建立对视、自然调整、重新对镜三个阶段，没有要求眼珠全程锁死。
- [ ] 需要清楚读取的表情或台词放在回正/落稳并重新对镜之后。
- [ ] 转头、目标表情与身份稳定要求已转换为最小充分的正脸、侧脸、目标表情或脸部视频参考建议。
- [ ] 没有把 Facial Element 描述成服装、发型、妆容或道具一致性控制。

## C4. 原地表演与根位移

- [ ] `root_motion: locked` 明确标为内部需求标签，没有伪装成 Kling 官方字段。
- [ ] 用户实测失败只按原模型、工作流和约束登记，没有把共现措辞写成已证明的单一原因。
- [ ] Prompt 开头已定义人物站定、足底持续承重和人物—镜头距离不变，后续没有用全身动作改写该主体运动状态。
- [ ] 局部动作具有明确方向；零位移要求下没有混入朝镜头靠近、远离或“回到原位”的前后路径。
- [ ] 只有用户明确接受更换工作流时才另给 Motion Control，没有跳过文本修复。
- [ ] 匹配 `[USER-K3-02]` 条件时使用已验证的文本修复；模型、工作流、景别或动作方向改变时重新验收。
- [ ] 其他 Standard 修复若没有官方依据或用户生成验证，已标注“待验证实验版本”，没有晋升为稳定规则。
- [ ] 本轮新增模型结论已登记到 `references/evidence-ledger.md`。

## D. 对白

- [ ] 说话者、原文台词和 delivery 紧邻。
- [ ] 有说话前动作；有意从半句切入时已说明。
- [ ] 只有命名 speaker articulates speech。
- [ ] 听者对具体刺激作出反应，而不是 NPC 凝视。
- [ ] 台词后有闭口与 aftermath。

## E. 模型适配

- [ ] Seedance 使用连续因果 prose 和相对时序，没有伪造精确镜内时间控制。
- [ ] Kling 将配置和 Prompt 正文分离，规划标签没有冒充官方字段。
- [ ] Kling Standard/Omni 演员 Cut 情绪 Prompt 使用动态分段框架，时间从 0 连续覆盖总时长，标题时间前没有“约”；Motion Control 未套用该框架驱动动作。
- [ ] 分段边界根据本场动作负荷分配，正文已声明时间仅作节奏参考，并明确跨段连续、不停顿、不重置、不重新起势。
- [ ] Kling Custom Multi-Shot 每镜一个戏剧任务，逐镜时长总和等于总时长。
- [ ] Kling Motion Control 已提供动作来源、动作参考编排、Facial Element 计划和补充 Prompt；补充 Prompt 没有重复或冲突的动作时间线。
- [ ] Motion Control 素材不足时已明确缺口，并仅把 Standard 版本标为近似降级方案。
- [ ] 没有承诺完美口型、负面提示词服从或模型绝对优劣。

## F. 护栏

只加入当前场景需要的少量护栏。每条纯否定应尽可能转换为正向状态：

| 风险 | 正向替代 |
|---|---|
| 过度哭泣 | 一次成分打断句子；肩保持安静；峰值后进入明确余波 |
| 机械眨眼 | 删除 blink cue；必要时仅在决定边界一次普通眨眼 |
| 随机手势 | 双手保持任务位置，仅完成一次目标动作 |
| 持续盯视 | 为一次移视指定目标和回看/退出结果 |
| 对镜运动时锁眼 | 静止时建立对视；运动时在镜头区域内自然调整；回正或落稳后重新对镜 |
| 人物走近再退回 | 登记限定范围的用户实测；先重写主体运动状态，删除前后向路径和全身返回任务，只保留有方向的局部动作；匹配条件下使用 `[USER-K3-02]` 已验证组合 |
| 听者嘴乱动 | 仅命名 speaker 发音；听者不产生 speech-like mouth cycling |
| 死脸 | 身体主要静止，但保留一次有目的的视线、手或肩部变化 |
| 情绪重置 | 结尾保持新的视线、距离、姿态或未完成任务状态 |

## 默认输出验收

最终回答必须包含：

1. 模式判断与必要假设；
2. 一句话导演逻辑；
3. 所需模型的可复制 Prompt；
4. 三条可观察成功标准；
5. 一条主要不确定性或调试建议。

分析保持简短。不要输出内部候选策略、完整检查表或证据论证，除非用户要求。
