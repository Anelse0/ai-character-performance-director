# 高潮、阈值与失败修复

## 强度定义

- `L1_leak`：一个低幅度变化泄漏，控制成功。
- `L2_breach`：一句话、任务动作或控制尝试失败一次，角色仍能行动。
- `L3_dysregulation`：呼吸、语言或动作中的一个通道短暂失去协调；峰值短暂，之后仍有状态。

只选择一个目标强度。不要用多个抽象副词连续加码。

## 高潮架构

按需选择，不要求每场完整出现：

```text
pressure / stakes
→ optional confirmation or silence
→ optional control or recovery attempt
→ threshold: control fails, truth is accepted, or a choice becomes irreversible
→ brief release OR refusal to release OR direct decision
→ fatigue / numbness / recovery / residual agitation / continued action
```

高潮的核心是跨过控制、认知或行动阈值，不等于持续哭喊。角色终于问出问题、停止争辩、说出最短真话或直接离开，都可以是峰值。

## 场景策略选择

以下只提供选择维度，不是固定身体配方：

- 强忍眼泪：目标是维持交流或任务；让一句话缩短、任务动作停一次或恢复尝试失败。泪、眨眼、吞咽均非必选。
- 压抑愤怒：目标是控制行动或建立边界；减少动作，选择一次握紧后主动释放、突然静止或语速变慢。
- 背叛领悟：根据角色选择核对、质问、退出或立即行动；不强迫先哭、先退或延迟反应。
- 表白/坦白：冲突在说与不说；使用假启动、最短真话和说完后的等待。
- 分手：让排练过的行动在一个具体刺激处出现破口，并通过钥匙、距离、朝向或触碰撤回来落实决定。
- 惊恐：定位威胁或身体信号，从寻找支点、求助、逃离、freeze 中选择少量通道；不固定为尖叫或过度换气。
- 情绪崩溃：维持功能失败一次或两次，只有一个成分突破；余波可以疲劳、麻木、恢复尝试或残余激越。

## 失败诊断

### 过度表演

原因：峰值从第一帧开始、强度词过多、多个通道同时变化。

修复：删除强度副词；建立 onset；保留一次主要破口和明确余波。

### 死眼或空白停顿

原因：只写静止/不动，没有刺激对象和状态差。

修复：指定 eyeline 或相关物件；在停顿中只加入一次视线、任务动作或可见呼吸变化。

### 机械眨眼与面部循环

原因：使用 `blinks nervously`、反复频率词或面部零件清单。

修复：首先删除眨眼；若剧情必须，只测试一次边界眨眼。把持续表情改成一次出现与释放。

### 随机手势

原因：抽象情绪没有行动对象。

修复：让手保持任务基线，只完成一次目标动作，例如 reach-stop、grip-release、放下或收回物件。

### 情绪跳变

原因：没有 baseline/onset，或跨镜未继承状态。

修复：写清 first change；把上一镜 end state 作为下一镜 baseline。

### 高潮过早或持续太久

原因：直接写哭喊、崩溃，未给压力或控制责任。

修复：增加一个具体压力/确认或恢复尝试；峰值只占一个 beat；指定余波。

### 嘴持续运动

原因：话轮不清、长对白、听者状态缺失。

修复：缩短台词；固定角色名；动作先于台词；仅命名 speaker 发音；为听者写非语言任务。

### 结尾归零

原因：没有 end state，模型回到参考图初态。

修复：明确最后的目光、手、距离、未完句或行动后果；必要时写“不恢复开场笑容”的正向等价状态。

## 三步修复法

```text
1. 定位一条具体失败行为。
2. 删除两个与其竞争的动作，保留 trigger + 主变化 + end state。
3. 用有限、正向、可见的动作替换纯否定，再做多次生成验证。
```
