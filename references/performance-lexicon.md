# 表演词条库(Performance Lexicon)

## 0. 定位:写作词汇表,不是情绪查找表

本库收录**已验证来源**(用户验证成片的 prompt、官方指南)中反复出现、模型可渲染的**描述词条**,按**身体通道**组织,供写 L4 时取用精确措辞。

它与反模板原则(`[ACT-RESEARCH-02]`:面部动作不是情绪指纹)兼容的关键在组织方式:**词条按通道索引,不按情绪索引**。决定性证据:同一批词条(红眼、蓄泪、唇颤、颌紧、指蜷、呼吸变化)同时出现在"愤怒争吵"(`[USER-SD25-02]`)与"深情告别"(`[USER-SD25-01]`)两个相反场景——词条本身不携带情绪含义,含义来自排序与上下文。官方也背书外化词汇的存在(`[S20-FMT-01]` 官方「抽象情绪→外化动作」示例表),但该表是**教学示例**,不是查找答案。

**禁止**:建立"情绪 X → 固定选用词条 a/b/c"的映射;把词条当作省略场景推导的捷径。选词条前必须先完成 target/WANT/tactic 推导——词条回答"怎么写准",不回答"演什么"。

## 1. 词条库 = 资产:增值机制

本库的价值随使用**复利增长**,机制是一个闭环:

```text
生成 prompt(取用词条+至少一处本场专属新细节)
→ 用户实拍验证
→ 通过的 prompt 逐字存档为 fixture
→ 从 fixture 中"挖矿":新词条/新变体/新阶梯登记入库(带出处)
→ 下一次生成的词汇更准、覆盖更广
```

维护规则:

- **只收验证来源**:词条必须出自 `user_verified` fixture 或官方指南;设计稿/未验证 prompt 不入库。
- **每条带出处与域标签**:出处=证据编号;域=该词条被验证过的场景域(当前全部为"夜内景/越肩/关系戏/年轻女性"窄域——跨域使用时词条只是候选,不是已验证)。
- **阶梯词条记完整刻度**(如泪水计量),生成时按情绪进度取刻度,不跳级、不一步到位。
- **失败也入账**:某词条在成片中失效时,在词条下登记失效条件(参照证据门禁格式)。

## 2. 避免同质化:四条硬规则

词条库最大的风险是让所有成片长一个样("每条视频都有一滴泪落下不擦")。对抗机制:

1. **署名细节稀缺制**:每条 prompt 里最具记忆点的 1–2 个细节(如"一滴泪落下不擦""想笑没笑成")视为**署名细节**;同一署名细节**不得在连续两次生成任务中重复使用**,除非用户点名要。普通词条(呼吸、视线)不受此限。
2. **本场专属配额**:每条 prompt 必须包含**至少一处不来自本库**、只对本场情境成立的新细节(来自道具、关系、空间或台词的独特性——如 SD25-02 的"指着自己胸口"绑定台词"我一遍遍告诉你我的感受")。库覆盖 ~80%,专属细节补 20%,这 20% 是成片不同质的来源。
3. **变体优先**:词条列出变体时,优先选未用过的变体,而不是默认第一个。
4. **通道轮换**:同一情绪任务在不同场次优先换主承载通道(上次走眼/泪,这次走呼吸/手),除非景别限制。

## 3. 词条格式

```yaml
词条: <可直接写入 prompt 的描述短语>
通道: 眼/泪 | 唇/颌 | 呼吸/肩 | 手 | 嗓音/delivery | 沉默 | 视线 | 重心/幅度
类型: 单点 | 阶梯 | 包络
出处: [证据编号或 official]
域: <已验证场景域>
变体: <2–3 个同义但画面不同的写法>
署名细节: 是 | 否
```

## 4. 通道词条(当前库存)

来源限定:`[USER-SD25-01]`、`[USER-SD25-02]`、`[S20-FMT-01]` 官方表。域:夜内景/越肩/关系戏(officia l 表无域限定但无成片验证)。

### 眼/泪(阶梯——泪水计量,两样本共有)

```text
eyes slightly red → eyes clearly red / reddened eyelids → tears gather (brim, not falling)
→ inhales to force tears back → one tear slowly falls (does not wipe it away)【署名】
→ more tears fall → eyes wet and shining
```
从不写"她哭了",只写眼泪所处刻度。official 表对应:「眼眶泛红、泪水在眼眶里打转但没有落下」。

### 视线(单点)

- 移开视线数秒→强迫自己看回(SD25-01/02 共有;变体:短暂垂眼再抬起 / briefly looks away, then immediately looks back)
- 目光开始动摇 gaze wavers(SD25-01/02)
- 锐利回看 eyes become sharp again(SD25-02,外驱触发后)
- 专注凝视如同最后一次记住对方的脸【署名】(SD25-01)
- official 表:眼神闪躲(紧张)/眼神如刀般锐利(愤怒)

### 唇/颌(单点+阶梯)

- 唇微张欲言又止 lips part as though about to speak, then stop(SD25-01)
- 唇部细微颤抖 → 开始明显颤抖(阶梯,两样本)
- 下颌绷紧 jaw tightens / tense jaw(两样本;official:下颌线紧绷)
- 苦笑一闪 brief, disbelieving, bitter smile【署名】(SD25-02)
- 想笑没笑成 wants to smile to soften it, but cannot manage it【署名】(SD25-01)
- 喉咙发紧 throat tightens(SD25-01)

### 呼吸/肩(包络,两样本共有)

- 深吸一口气(准备动作)/ 呼吸变重 → 越来越快 → 不均匀 uneven(阶梯)
- 肩随呼吸微微起伏 / 肩几乎不可察地颤抖(SD25-01)
- 一次极轻破碎的呼气 one small, broken exhale(SD25-01)
- official 表:胸口剧烈起伏(愤怒)/长舒一口气+肩膀完全放松(释然)

### 手(单点)

- 手指微微蜷起收紧 fingers subtly curl and tense(两样本;official:手指无意识攥紧衣角)
- 抬手指向自己胸口(绑定台词的强调动作,SD25-02)【署名】
- 双臂自然垂在身侧(基线姿态,SD25-02)

### 嗓音/delivery(句内演化,SD25-02 为主)

- 后半句声音开始发抖 voice begins to shake during the second half
- 最后几个字说得非常轻 the last few words spoken very softly
- 语气在第二句变重 tone becomes heavier during the second line
- 声音比刚才更轻 voice quieter than before(SD25-01)
- 从牙缝里挤出话语(official 表,愤怒;本库尚无成片验证)
- 不再提高音量、语气变得很轻(终段收势,SD25-02)

### 沉默(beat 化,两样本共有)

- 先沉默几秒再开口 stays silent for a few seconds first
- 长停顿 a long pause(句间)
- 说完后数秒沉默,只有不均匀的呼吸
- 整个房间突然安静下来(转段标记,SD25-02)

### 重心/幅度(包络,SD25-02)

- 动作幅度包络:克制(动作收着)→ 前倾、手势变得可见 → 逐渐减少 → 完全静止
- 向前一步 steps forward(升级标记;注意 Kling 上有根位移风险)

## 5. 镜头/声音词条(简)

- **手持呼吸感**:close and handheld, subtle breathing motion and natural shake(SD25-02;争吵/对峙域)
- **本场显式运镜耦合**:情绪升高时缓慢靠近、沉默时静止(SD25-02;必须写成本场设计,禁止当自动规则)
- **声音白名单**(SD25-02):渐快的呼吸/对白(标语言)/画外短回应/衣料摩擦/脚步/房间底噪/句间沉默
- **输出通道排除**(official):无 bgm/不要字幕/无文字叠加/无旁白/无 UI

## 6. 与生产流程的接口
