# 表演内核

## 1. 目标

把内在描述转换为具有因果位置的可观察变化：

```text
角色正在争取什么
→ 什么刺激改变了行动条件
→ 角色选择什么策略
→ 哪个低幅度变化首先泄漏
→ 角色采取什么行动或控制
→ 镜头结束时什么仍然存在
```

情绪只作语义锚点。真正控制生成的是目标、刺激、策略、顺序、幅度、次数和结束状态。

## 2. 建立语义对象

依次确定：

1. `scene_state`：刺激发生前，角色在做什么、知道什么、身体状态如何。
2. `relationship`：对方对角色意味着什么；关系影响距离、礼貌、风险与表达许可。
3. `want`：角色此刻试图获得的可行动结果。
4. `hide_or_conflict`：仅在确有压抑、否认、改道或两难时加入。
5. `trigger`：画面或声音中可定位的词、物件、动作、停顿或变化。
6. `display_policy`：公开表达、克制、否认或改道。
7. `intensity`：L1 泄漏、L2 一次破口、L3 某一功能短暂失调。
8. `ending`：残留、恢复尝试、继续行动、残余激越或阈值切断。

若用户只给情绪，先依据已有情境补 WANT 和 trigger。没有情境且多种补法会产生完全不同的戏时才追问。

## 3. 生成 Playable Strategy

不要从情绪查动作。先从角色下一步要做什么生成至少两个候选策略，再选择最符合关系、权力、风险与剧情阶段的一条。

可用的策略方向不是模板，而是行动分类：

| 行动方向 | 角色可能在做什么 | 可见结果应围绕什么组织 |
|---|---|---|
| approach / comfort | 靠近、帮助、获得回应 | 距离、触碰意图、等待许可 |
| withdraw / protect | 退出、遮挡、保存尊严 | 距离增加、停止追随、收回物件 |
| confront / set boundary | 质问、纠正、阻止 | 静止、扎稳、精确台词或阻断动作 |
| repair / confess | 承认、道歉、修复 | 假启动、最短真话、等待对方反应 |
| verify / seek information | 核对证据、确认意义 | 在证据与人物间建立一次有目的的视线或动作 |
| orient / protect from threat | 定位威胁、寻找出口或支点 | 动作中断、定向、随后采取保护行为 |
| hold function together | 继续任务、维持交流 | 任务动作继续，一次泄漏或恢复失败 |
| redirect / deny | 掩盖、换题、把冲动改到安全动作 | 语言与一个身体通道形成有动机的矛盾 |

选择规则：

- WANT 优先于情绪强度。
- 关系许可决定靠近还是保持距离。
- display policy 决定直接行动还是出现“冲动—中止—残留”。
- 剧情阶段决定核对、行动、释放还是余波，不默认所有人先核对。
- 同一策略只保留一个主要身体语法，避免同义动作重复。

### 非模板性自检

在写 Prompt 前回答：

- 如果把情绪词删掉，动作是否仍然清楚地服务当前目标？
- 同一情绪换成不同 WANT 后，策略是否会改变？
- 动作是否只对本场的具体刺激成立，而不是能贴到任何场景？

若三项任一为“否”，重新选择策略。

## 4. 组装 Beat Graph

### 节点定义

- `baseline`：提供可比较的起始状态，不必是中性脸。
- `trigger`：刺激必须能被观众定位。
- `orient/process`：即时定向或短处理，二选一；不机械添加延迟。
- `first_change`：第一次可辨认状态差。
- `action/control/redirect/choice`：角色策略的真正落实。
- `threshold/release`：可选；短暂越过控制、认知或决定阈值。
- `end_state`：明确镜头最后由谁持有什么状态。

### 节点选择

- 参考图已有强起始表情时，不重复建立中性 baseline。
- 惊跳、威胁定向、身体失衡可即时反应；认知复核、克制与语言规划可有短处理。
- reveal 场景可直接行动；restrain / deny / redirect 才需要具体控制或改道。
- 高潮不等于哭喊；真相被接受、问题终于问出、行动不可逆也可构成 threshold。
- end state 默认不回到开场状态，除非剧情就是恢复伪装。

## 5. 表演意图与通道预算

每个 beat 只安排一个主要表演意图。简单表演选择一个主通道，必要时加入一个可见辅助通道：

| 构图 | 优先可读通道 | 谨慎使用 |
|---|---|---|
| 特写 | 视线、笑意消失、嘴/下颌、说话边界 | 大幅身体动作、复杂走位 |
| 中近景 | 视线、嘴/下颌、上胸/肩、手、声音 | 脚步与精确全身重心 |
| 中景 | 手、姿态、距离、朝向、声音 | 极细眼睑或喉部动作 |
| 全身 | 重心、步伐、接近/退出、目标动作 | 极细微表情作为唯一信息 |

呼吸只有在上胸/肩可见或音频可听时才是有效指令。吞咽只有在喉部可见且临近说话边界时才可作为待测选择。眨眼通常不承担情绪信息；若剧情确需，只限定一次并放在说话或决定边界。

机械联动不按身体零件逐个计数：一次轻跳中的屈膝、离地、落地缓冲属于同一个 Motion Unit。若头、手、眉、嘴、重心分别承担探头、招手、挑眉、嘟嘴、蹦跳等独立任务，则属于动作并发，不是机械联动。此时按顺序处理：

1. 保留最直接服务 WANT 的主要行动；
2. 删除装饰性或重复表达的动作；
3. 能自然承接的动作改为串行；
4. 必须精确同步或完整保留时，交给对应模型的动作控制工作流。

Motion Unit 的机械拆解、速度、方向、接触与收势规则见 `references/kling-motion-control.md`。

## 6. 可观察语言

优先：

```text
fades / stops / stills / releases / returns / withdraws
begins to... then stops
prepares to... but chooses not to
once / one brief / for one beat / half a step
when... / only after... / after the unfinished word...
```

慎用：

```text
subtle / restrained / internal / realistic / emotional
```

这些词只能作为具体动作之后的幅度护栏，不能独立承担表演设计。

删除：重复情绪同义词、不可见比喻、无对象的环顾、无次数的紧张眨眼、互相竞争的动作和无法验证的精确秒点。

## 7. 时长预算

| 时长 | 主 beat 数 | 推荐责任 |
|---:|---:|---|
| 4–6 秒 | 2–3 | trigger、first change、end state |
| 7–10 秒 | 3–5 | 可加入 baseline、处理和行动选择 |
| 11–15 秒 | 5–7 | 可加入一次恢复失败、短对白、听者反应或短释放 |

台词占用嘴部与时间预算。台词越长，越应删除面部零件指令或拆镜。

## 8. 证据边界

- 面部、身体、呼吸与情绪均为多对多关系。
- FACS 描述可见运动，不证明角色真实感受。
- “微表情”在本 skill 中仅指相对基线的短暂低幅度变化。
- 模型对精确微动作、负面约束、口型和时序的服从必须通过多次生成验证。
