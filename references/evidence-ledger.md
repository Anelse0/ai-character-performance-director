## 晋升规则

本规则由用户于 2026-08-11 明确要求：写入 skill 的模型能力、失败原因与稳定修复，必须有正确来源或经过用户明确生成验证。

- `official`：模型厂商官方文档明确支持，可写成平台事实；保留适用版本和边界。
- `user_approved`：用户明确批准的 Skill 工作流、输出契约或证据政策；可作为设计要求，不构成模型效果验证。
- `user_verified`：用户报告了实际生成结果；只在相同模型、工作流、输入条件和约束范围内成立。
- `experimental`：只有修复假设，尚无官方依据或用户成片验证；可以作为待验证输出，不能进入稳定规则。
- `rejected`：用户实测无效或与官方资料冲突；不得再次作为默认建议。

新增稳定规则必须引用下列证据编号。推断不得借“工程经验”绕过门禁。

### [S25-FORMULA-01] Seedance 2.5 官方 prompt 结构(一手)

- 状态：`official`
- 来源：《Doubao Seedance 2.5 提示词指南》官方 PDF「提示词写作建议·基础写作」,2026-08-17 一手核实。
- 官方结构(逐字要点):(1)**(R2V)素材指代**——按上传顺序编号(图 1/视频 1/音频 1),明确每个素材的用途(谁是形象/音色/动作/场景),文本绑定,「不建议只在图片里呈现映射信息」;(2)**一句话概述**——主体+地点+事件+题材/风格+特殊运镜;(3)**具体情节描述**——用时间戳或「镜头 N」切分,逐段描述画面、运镜、动作、台词、音效,尽量正向描述;(4)**结尾**——补充贯穿始终的细节:机位/运镜、环境/场景、声音、氛围。
- 负向描述(官方):**仅支持字幕与音频控制**(「不要字幕」「无 bgm,只生成环境音和动作音」「不要任何声音」),且音频可分维度单独控制(音效/bgm/对白)。
- 其他官方写法:镜头语言通识词直接写,小众名词用「名词+描述性解释」;转场写清触发点/方式/时间;动作优先概括性描述、只在有记忆点处写细节;表情用描述性语句、减少成语;参考素材足够精准时只做「指代」、减少画面复述。
- 官方还提供 prompt 调优 skill:`npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe`(本机无 node 未安装,仅登记入口)。

### [S20-FMT-01] Seedance 2.0 官方 prompt 结构(一手,纠正旧条目)

- 状态：`official`
- 来源：《Doubao Seedance 2.0 系列提示词指南》官方 PDF(火山方舟,用户提供,2026-08-17 一手全文核实)。
- **纠正**:本条目旧版(基于搜索摘要)称 2.0 "按 0–3s/3–6s 分时段分镜"——**错误**。官方一手原文:「模型对精确时间(如 0–3 秒)的支持不稳定,强行限制时长可能导致生成结果异常」「不强制限制每段时长,优先让模型根据剧情自然生成节奏」;2.0 **只响应镜头序号(镜头 1/2/3),不响应时间戳**。
- 官方进阶公式:精准主体+动作细节(必需)+场景环境+光影色调+镜头运镜+视觉风格+画质+约束条件(建议)。
- 主体定义句式:「将<图片 N>中的[2–3 个稳定特征]定义为<主体 N>」;多主体分别定义并持续用同一标签;未定义时用 `张三@图片1` 强调绑定。
- 每镜四部分组织:①运镜或切换方式 ②主体动作与表情 ③位置/空间变化 ④**音频信息(音效/人声/bgm)**。
- 动作规则:肢体细化+幅度/速度/力度量化;**优先低缓连续小动作**;写明前后动作惯性承接;**情绪具象外化**(官方给出「抽象情绪→外化动作」示例表:悲伤/喜悦/紧张焦虑/愤怒/释然)。
- 运镜:「一个镜头里尽量只指定 1 种运镜方式」。
- 约束词模板:无字幕/不要 Logo/不要水印。
- **视频延长 vs 分段拼接**:单一场景「文戏」(长对话、情绪递进、单一路径移动)用**视频延长**实现连贯一镜;剧情转折或快节奏「武戏」用分段拼接;实际通常两者结合。
- 素材配置策略:角色锚定/场景定调/运镜参考/节奏氛围四种功能角色,推荐共 4–5 个素材;**不建议用满素材上限**(过多导致特征优先级混乱)。输入上限:≤9 图、≤3 视频、≤3 音频、总数 ≤12。
- 用法:2.0 的分镜结构 = `镜头 1/镜头 2…` **无时间标注**;情绪表演仍用结构化分镜,但时间段标注仅限 2.5。

### [USER-K3-01] 原地约束失败

- 状态：`user_verified`
- 用户报告日期：2026-08-11。
- 条件：Kling 3.0 Standard、8 秒、单人演员 Cut、稳定单镜中近景、无台词；Prompt 包含向镜头前倾、迎接/拥抱姿态及随后回落，同时多次写明不迈步和保持原位。
