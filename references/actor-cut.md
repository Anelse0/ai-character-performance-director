# 演员 Cut 编排器

## 模式契约

演员 Cut 的内容主体是演员的表演过程，而不是完整剧情覆盖。摄影机持续把观看责任交给一个主要 performer；刺激可以来自画外音、画外人物、道具、记忆触发或演员自己的台词。

包括：

- 无台词情绪反应；
- 独白、短台词、试镜片段；
- 对画外声音或人物的听戏；
- 双人画面中由一个演员持有的连续 reaction shot。

不因为出现台词就自动变为剧情表演；只有行为实际推进关系、信息或事件时才切换到 narrative。

## 默认镜头契约

- 单镜、稳定构图、中近景或特写。
- 一个主要 performer，一个明确 trigger。
- 环境只保留刺激来源、支点或承载动作的关键物件。
- 默认不使用复杂推拉、环绕、走位和光线变化。
- 每次仍按 `references/camera-direction.md` 主动判断镜头；静止是保护表演 onset、台词归属和余波的正式选择。
- 使用运动镜头时，只服务一次策略、关系、信息或观看距离变化，并编译为一个 Camera Unit。
- 不因演员开始独白、说出重句、哭泣或进入高潮自动推近。
- 演员 Cut 出现连续转头、手势、蹦跳或遮脸等复杂动作时，先做动作复杂度路由；不要因为仍是单镜就默认 Standard 可以精确完成。

## 编排方法

### 先建立镜头前的行动对象

演员 Cut 也必须有 `target_person` 与 `expected_effect`：人物不是向摄影设备展示情绪，而是在影响镜头前、画外或想象中的具体对象。

- 直接对镜：说明人物希望镜头前的人注意、回应、相信、原谅、留下或作出本场特定变化；不要把这些例子当固定策略清单。
- 画外刺激：eyeline、倾听和行动指向同一个画外对象。
- 独白：区分对镜交流、向画外对象说话与自我整理，不能默认都是直视镜头。

高潮必须来自人物加大、改变或放弃 tactic，或终于确认行动结果；不能只把笑容、哭泣或身体幅度放大。回落必须来自反馈或重新控制，没有反馈时以等待、继续争取或主动结束收束。

镜头若移动，触发应与上述策略变化或反馈相邻，但不要求精确卡秒。起幅、主运动、停止和落幅必须保护承担关键信息的眼神、动作或台词；演员已有复杂动作时优先静止。

### 无声反应

```text
可比较的起始状态
→ 画外或画内刺激
→ 即时定向或短处理
→ 一个主要状态差
→ 一次指向 target 的行动、控制或选择
→ 可定位反馈或明确等待
→ 可保持到切点的关系残留
```

不要把“静止”写成全身冻结。应指定什么保持不变、什么只变化一次。

### 独白或短台词

```text
说话前的目标动作
→ 准备呼吸或视线选择
→ 精确短句
→ 句内最多一个变化
→ 说完后闭口并承受沉默
```

独白不是连续朗读。若台词较长，选择一个转折词作为表演变化位置，其余时间保持行动目标一致。

### 画外音刺激 / 听戏

画外刺激必须具体到一句话、一个关键词、声音变化或停顿。演员的 eyeline 应有稳定对象；若移视，写明看向什么以及是否返回。

### 对镜表演

“注意力始终给镜头前的人”表示行动持续指向 `target_person`，不等于运动过程中锁死眼珠。演员静止时建立清楚、符合关系的镜头眼神；头部或身体运动时，眼神在镜头目标区域内自然调整；动作落稳后重新建立明确对视。详细规则见 `references/kling-motion-control.md`。

对镜招手、击掌、拥抱邀请、递接物件或镜头表面动作还必须读取 `references/interaction-performance.md`。先决定对象是否获准可见、隐藏后动作是否物理成立与可读，再编排情绪；不能用“演员 Cut”绕过实体门禁或接触依赖。

### 原地表演

用户要求人物不位移时，提取 `spatial_lock: hard` 与 `root_motion: locked`，两者都是本 skill 的内部需求标签。若用户已经实测某个 Standard Prompt 出现位移，把该结果登记为限定范围的 `known_failure`，不得自行断言某个动作词是唯一原因。Kling 的证据边界、待验证 Standard 版本和 Motion Control 路由见 `references/kling-motion-control.md` 与 `references/evidence-ledger.md`。

## 通道选择

- 特写：一个视线或面部状态差为主；嘴/声音为辅助。
- 中近景：可用一次手部、肩部或任务动作支撑主变化。
- 有声输出：声音只给一个主要变化，如速度变慢、第一词卡住或句尾变薄。
- 无声输出：不要依赖只有声音才能感知的呼吸或 delivery。

## 强度处理

- L1：一次泄漏，角色仍完全维持功能。
- L2：一个句子、动作或控制尝试失败一次，功能仍在。
- L3：呼吸、语言或动作中的一个通道短暂失调，峰值很短并留下状态。

演员 Cut 不默认需要完整升级弧。4–6 秒只保留 trigger、一次指向 target 的可见 tactic 与 ending；不额外虚构 obstacle、反馈或完整高潮回落。

## 结束画面

必须写清：

- 目光最后停在哪里；
- 手、姿态或嘴部是否保持/释放；
- 角色是恢复、继续任务、等待、残余激越，还是在阈值处切断。

结束不能无意回到参考图的初始笑容或中性状态。

## 常见错误

- 用持续皱眉代表整个情绪；
- 为避免过演而禁止所有动作，得到死脸；
- 第一帧直接念台词，没有说话入口；
- 画外刺激不具体，演员像凭空变脸；
- 眨眼、吞咽、呼吸和唇颤同时出现；
- 说完台词继续 speech-like mouth cycling；
- 镜头运动抢走微表演。

## 输出要求

导演逻辑应明确“对象—刺激—WANT—tactic—结尾”。Prompt 中不展示内部 YAML、stakes、潜台词或多个候选策略，只输出最终选择的可观察载体。

## Kling 演员 Cut 情绪输出框架

仅当目标模型为 Kling Standard/Omni、任务是演员 Cut 情绪表演且未使用 Motion Control 时使用本框架。框架固定，表演内容与分段必须动态生成：

1. 开头写总时长、单镜、景别和有无台词。
2. 紧接连续性声明：时间范围仅作为节奏参考，动作可以自然提前或延后；所有变化连续衔接，不在分段边界停顿、重置或重新起势。
3. 根据实际 Beat Graph 使用 3–5 个分段。简单表演可以把“回落”和“恢复”合并；复杂表演才增加独立阶段。
4. 时间从 `0` 开始，以总时长结束；各段无空缺、无重叠。时间边界根据动作负荷动态分配，不套用固定比例。
5. 标题使用 `【0–1.4s｜正常状态】` 形式。数字必须具体，时间前不得添加“约”。
6. 每段写上一段动作如何继续、完成或改变；不得把每个标题写成一次新的动作启动。
7. 最后集中写身份、人数、动作次数、连续性和常见伪影护栏。仅保留本场相关约束。

格式骨架：

```text
[总时长]稳定单镜[景别]，[有台词/无台词]。时间范围仅作为节奏参考，动作可以根据表演自然提前或延后；所有变化连续衔接，不在分段边界停顿、重置或重新起势。

【0–[动态边界]s｜[起始状态]】
[人物、构图、基线]

【[动态边界]–[动态边界]s｜[变化阶段]】
[刺激落下、第一次变化；动作承接上一段]

【[动态边界]–[动态边界]s｜[行动或高潮]】
[一次主要行动；避免重新起势]

【[动态边界]–[总时长]s｜[余波/恢复/阈值切断]】
[结束状态]

[定向护栏]
```

上述是输出格式，不是固定情绪模板。阶段名称、段数、动作、高潮位置与时长边界都必须服从本场 target、WANT、tactic、反馈、强度和 ending。
